# 伊東Instagram改善提案

伊東市の事業者向け Instagram 改善提案をまとめた資料サイトです。
もともと ito-chamber.portal の `instagram/` 配下にありましたが、単独のリポジトリとして独立させました。

## 構成

- `index.html` … 提案トップ（4分野の入口）
- `group/iimono/` … いとうのいいもの（伊東ブランド認定事業者）
- `group/okashi/` … 伊東お菓子ぃ共和国
- `group/jizakana/` … 伊豆・いとう地魚王国
- `group/furusato/` … 伊東市ふるさと納税
- `tokens.css` … 共通デザイントークン

## 公開URL

GitHub Pages: https://ryo-itojournal.github.io/ito-instagram/

## ポータルとの関係

デジタルミュージアムや各展示室、ふるさと納税プロトタイプは ito-chamber.portal 側にあり、本リポジトリからは絶対URLでリンクしています。
